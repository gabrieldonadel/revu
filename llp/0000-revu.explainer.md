## Overview

revu is a macOS menu bar app for reviewing GitHub pull requests. It shows the
pull requests where you are a requested reviewer, notifies you when a new
request arrives, and can run an AI review of a pull request driven by a
configurable skill file.

It is built on Exact2 (`ccheever/exact2`: Contract compiled to a plan, an
AppKit presenter on macOS, app logic in `app.ts` behind a typed data seam) and
uses LLP for its own design corpus. The first repository (`expo/exact`) was
the original target; it is research now, not authority (2026-09-28).

## Architecture

Two processes, deliberately:

- **App** (`revu-app/`) — the Exact2 app: `app.contract` is the UI,
  `app.ts` is sign-in (device flow), GitHub polling (`net.fetch`), the token
  (`secret.keep`, the Keychain on macOS) and seen-state (SQLite under
  `app:/data`). Windowed today; the menu bar item and notifications are
  capability asks against Exact2 (LLP 0003).
- **Sidecar** (`sidecar/`) — a Bun daemon on loopback for what the app cannot
  do: run `git` and an AI agent for the review (the AI-review runner). Owns
  nothing secret on disk.

LLP 0001 records the split and why polling moved into the app on Exact2.
