## Overview

revu is a macOS menu bar app for reviewing GitHub pull requests. It shows the
pull requests where you are a requested reviewer, notifies you when a new
request arrives, and can run an AI review of a pull request driven by a
configurable skill file.

It is built on Exact (Contract UI, AppKit host) and uses LLP for its own
design corpus. The runtime is linked to the `expo/exact` branch that carries
LLP 0570 (desktop notifications) until that PR merges.

## Architecture

Two processes, deliberately:

- **App** (`src/`) — the Exact app: the menu bar item, its native menu, the
  detail window, settings, and notifications. Owns the GitHub token in the
  Keychain.
- **Sidecar** (`sidecar/`) — a Bun daemon on loopback: GitHub polling, the
  SQLite state, and (later) the AI review runner. Owns nothing secret on disk.

They talk over `http://127.0.0.1:<port>` for requests and a WebSocket
`/events` for pushes. The split and the transport are decided in LLP 0001; the
reasons are recorded there, not here.
